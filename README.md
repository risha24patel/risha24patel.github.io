# Risha Patel - Professional Portfolio

A responsive, accessible portfolio highlighting AI evaluation, coding-agent assessment, data analytics, and professional experience.

## Live site

https://risha24patel.github.io/

## Files

- `index.html`: page content, experience, project summaries, skills, and education.
- `styles.css`: responsive layout, typography, and print styles.
- `script.js`: accessible mobile navigation and project filtering.
- `social-preview.png`: social sharing preview.
- `favicon.svg`: original monogram.
- `.nojekyll`: enables direct static file publishing.

## Edit and publish

Edit the HTML content or CSS and commit changes to the `main` branch. In repository Settings > Pages, choose **Deploy from a branch**, `main`, and `/ (root)`.

No build step, package installation, API keys, or paid hosting are required. The page also works when opened directly from `index.html`.

## Content notes

Project artwork is illustrative, not screenshots of employer systems. Project descriptions reflect professional responsibilities. The financial analytics project identifies SQL and Tableau as its documented tools; the broader toolkit is listed separately. Update role dates when experience changes. The original resume PDF is excluded from the public upload.
